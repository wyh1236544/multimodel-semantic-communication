# 图文多模态语义通信项目

本项目研究如何在带宽受限且不可靠的通信信道中联合传输图像与文本，并利用 Common 共享语义、接收可靠性估计、差异保护与安全生成恢复，同时兼顾像素重建、文本恢复和高层语义保留。

完整项目背景、系统框架、V6.1–V10 版本演进、已记录实验结果、证据局限和待完成实验见：
