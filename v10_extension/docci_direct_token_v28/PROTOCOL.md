# V28：独立模态连续 token 的低 SNR 适应

2026-10-20，实验分支 `experiment/direct-token-low-snr-v28`。新结果尚未运行。

## 问题与非目标

问题：在固定单次传输资源下，把负 SNR 真正纳入可微训练，能否提高独立图片/文本恢复质量？
不再训练图文互促，不增加 Common、联合编码器、CLIP、Long-CLIP、BLIP、扩散生成、LoRA、原文数字旁路或重复发送。既有所有版本和结果只读保存。token 化、连续 JSCC 本身不是新的发明；本分支是可复现的低质量链路适应实验，不宣称首创。

## 网络与沿用部分

- 图片：512×512 完整视野等比 letterbox → 冻结 sd-vae-ft-mse 原生 4×64×64 潜变量 → **V14 I2_shifted 空间编解码器** → 8×32×32 连续实数 → AWGN → 原 I2 接收器 → 冻结 VAE 解码器。使用 V14 expanded 固定最终权重。不是 V20 的 GuidedImage；没有残留跨模态融合层。
- 文本：完整描述，不超过 512 BART token → 固定 9 个公开 64-token 帧，每帧最多 62 个内容 token，空帧也发送 → 冻结 BART 编码器 → **released64 可训练压缩器**，每帧 32×64 实数 → AWGN → 可训练 memory 恢复器 → 冻结 BART 自回归解码器。使用 V18 noise_replay 固定最终权重；codec 参数数仍为 25,618,432。
- native source cache 是原生 VAE/BART 特征；**不能使用旧 wire 或 received memory 来训练发送器**。V28 每个视图重新执行压缩器→噪声→恢复器，TX 与 RX 都有梯度。
- VAE/BART 参数冻结，但反向计算通过其解码器到接收特征；不在训练解码部分使用 `no_grad`。源特征缓存意味着本轮不解冻预训练 source encoder，不称“所有参数端到端训练”。

## 主比较与固定预算

每条模态各自独立运行三条评价路径：冻结父权重、`normal_range`、`low_snr`。

| 组 | 初始权重 | 清洁视图，损失权重25% | 带噪视图，损失权重75% |
|---|---|---|---|
| normal_range | 同一模态的同一父权重 | clean | 均匀选择 0/5/10/15/20 dB |
| low_snr | 同上 | clean | 均匀选择 −8/−5/−2/0/5/10/20 dB |

两组数据、数据顺序、可训练参数、更新次数、有效 batch、两次 forward/backward、优化器、学习率和符号数相同。两份 **SNR 分布整体不同**，不把结果解释为某一个新增 SNR 点的独立因果作用。父文本已经接受过0–20 dB训练；父图像是clean训练模型，两个模态的改进幅度不能直接横比。

损失：文本为所有公开帧有效标签的 token 加权 CE；图像为有效非黑边区域 pixel MSE +0.01 latent MSE。无 KD、无新增语义损失，防止同时更改多项变量。

AdamW，LR默认3e−5，weight_decay=.01，warmup至多100步，线性降至10%，梯度范数上限1，FP32无AMP。模型保持eval以消除dropout随机差异，**eval不禁止梯度或优化器更新**。每组新优化器，不宣称精确断点续训；固定末次权重，不按验证分数选最佳。

## 信道与资源

首轮 **单位增益 AWGN**，不是 FSO、更不是物理光链路。`y=x+n`，每个实数分量噪声方差为 `10^(−SNR/10)`，发射均方功率1，加噪后不归一化。实部/虚部按两个实数折合一个复符号的资源计数，不传离散 token ID、不做QAM/FEC。

每模态收取32个复导频，单位增益已知，用独立64实数噪声观测估计噪声方差。图像条件输入来自导频，不使用SNR真值；文本接收器仍只接收固定实数payload，不新增免费CSI输入。clean的40只作图像旧接口的条件哨兵，实际 SNR 为null，不称“40dB测量”。

| 路径 | payload | 导频 | 每次总复信道使用 |
|---|---:|---:|---:|
| 图片 | 8192实数=4096复符号 | 32复符号 | 4128 |
| 文本 | 18432实数=9216复符号 | 32复符号 | 9248 |

R=1。双模态相加是13376复信道使用，但仍为两条独立路径；不声称联合压缩收益。3个噪声试验分别独立解码、分别计费，评价后先在每张图/每篇描述内部平均；**不是三次合并恢复，也不是免费重传**。连续实数没有确定 bit rate/BER，此处不虚构字节压缩比、Gb/s或AWG波形速率。

## 评价预先约定

clean、−10/−8/−5/−2/0/5/10/20 dB完整曲线。clean和−5dB另有真实不同样本shuffled、接收payload全零对照。打乱/清零是单模态传输依赖性检查，不是跨模态互促实验。接收端不读取源句子、源长度、padding mask或真实分段数。

图片 PSNR、SSIM，提供旧V20离线AlexNet/linear权重目录才测LPIPS；否则清楚标为NOT_MEASURED。文本报告原文、全部接收文本、WER/CER/BLEU2、重复、提前EOS/容量停止等。没有新BERTScore/事实评分；保留原始输出供后续独立离线语义评价，不能把WER下降等同于事实语义成功。

主比较固定为 **−5dB low_snr vs normal_range**；数值筛查：图片PSNR增益≥0.3dB且描述配对95%CI下界>0，clean增益CI下界≥−0.3dB；文本WER降低≥2个百分点且CI下界>0，clean增益CI下界≥−2个百分点。只是预先规定的工程筛查，不是普遍规律。不达标完整保留，不自动调门槛或再训。

按同一描述内噪声重复平均，再按描述做10000次bootstrap。单训练seed，CI不含训练随机性且多SNR未校正。qual_dev已反复使用，是探索性开发评价，不能称新的独立最终测试。旧train2048与qual_dev100缓存严格复用；不读取官方test/qual_test。

pilot为512TRAIN/16qual_dev/4轮/1个噪声试验；full为2048TRAIN/100qual_dev/10轮/3个试验。两者都不是DOCCI全量训练。smoke为8TRAIN/2qual_dev/2更新，仅clean/−5/0dB；没有正式效果意义。正式组从历史父权重重新初始化，**不继承smoke权重**。

## 验收与停机

先验证已保存父权重真实回放：文本clean生成token与V18一致；图像clean PSNR/SSIM与V14同样本一致。检查TX/RX真实梯度/参数更新、冻结骨干指纹、实际checkpoint保存回读、源文件SHA与完整矩阵。CPU独立验收重新计算文本指标、噪声/导频、配对预算，并可重验TX数组、旧缓存和权重SHA。PNG身份可验证，但**不声称CPU重新计算了所有未保存的浮点图像/LPIPS输出**。

启动至少16GiB可用显存、12GiB磁盘，运行保留2GiB可用显存/4GiB磁盘；不足即停，不杀他人任务、不自动减batch。一次只占用用户指定GPU，默认GPU1。独立报告/收集最多60分钟并受总任务预算约束，不再沿用旧180秒收集上限。

任何失败保留现场，禁止自动重启。`VERIFIED_COMPLETE.json`才表示独立验收和收集完成；`COMPLETE`/`SMOKE_COMPLETE`本身不证明性能成功。无数字对照新运行、FSO结论、跨模态收益或完整语义成功声明。
