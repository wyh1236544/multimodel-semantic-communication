# V10-A：导频感知的多信道语义保护

状态：候选研究实现；本地合成联调已执行，真实权重/GPU/COCO 性能未测。核验日期：2026-09-20。它不取代 V9 最优成果。

## 范围与成功条件

现有 `multimodel/v10_extension/` 内的隔离代码沿用 V9-A 主干及初始化权重，新增物理信道、公开排布协议、小型接收适配器、多信道训练与独立划分。从 multimodel 根目录启动，不创建并列项目。旧代码和成果不覆盖、不删除。成功分两层：物理/软件合同可以本地验证；优于 V9、论文贡献和真实 FSO 性能必须另做实验。没有模型能保证在接近零接收信息时恢复原图细节。

## 调研依据与采纳边界

1. [DeepJSCC，2019，原论文](https://arxiv.org/abs/1809.01733)：将可微信道放入端到端训练，研究 AWGN 和慢瑞利衰落。采纳“信道进入训练”和失配对照；不把它的图像结果直接移植为本项目成绩。
2. [ADJSCC，TCSVT，2021；arXiv v3，2022](https://arxiv.org/html/2012.00533v3)：用 SNR 条件化注意力和区间采样训练一个自适应模型；其 IV 节对每张图重复传输。采纳混合 SNR 和重复信道试验。论文的信道知识假设不能代替本项目的估计误差模拟。
3. [DeepJSCC-OFDM，2021，III-C](https://arxiv.org/html/2101.03909v1)：将导频估计、均衡等通信结构纳入学习系统。采纳“先物理估计/均衡、再小型可学习修正”的思路；本版不是 OFDM，也没有多径/循环前缀。
4. [Farid & Hranilovic，JLT 2007](https://www.ece.mcmaster.ca/faculty/hranilovic/publications/articles/07/jlt06IEEEFinal.pdf)：II 节描述光强、噪声及慢衰落；III 节描述湍流、路径损耗和指向误差。采纳乘性分解和零偏轴指向误差分布。本文实验参数并非从本项目链路测量拟合，不能声称已复现该文的户外容量结果。
5. [PJSCC，2024 预印本](https://arxiv.org/abs/2411.10178)：展示轻量条件模块用于不同信道的可行思路。仅作路线参考，未复现其网络；本版接收适配器不是该文提示模块的复刻。

以上是有限的一手文献核对，不构成“世界首次”的新颖性检索。

## 实际数据流

```text
物理链路 → 导频观测 → 接收端估计可靠性 → 64 实值反向 RF 模式码
                                           ↓
图像 VAE + LN 文本 CLIP → C/I/T → 发送端实际模式 → 前向物理模式头
                                  ↓                    ↓
                            公开固定索引             接收端解码模式
                                  ↓                    ↓
                           分组归一化 + UEP → 有噪物理信道
                                                       ↓
                           导频均衡 + 小型残差适配 → 独立重建索引
                                                       ↓
                          共享语义独立任务头 + 图像/文本联合恢复
```

发送端只使用反馈解码的模式，不知道接收端导频估计真值。主干接口收到的 SNR 是导频估计，用于接收端门控；新 packer 不读取这一数值或源文本长度来决定排布。模拟器真值只供信道传播与诊断；`--csi perfect` 是明确标记的理想上界对照。

## 信道与资源合同

### AWGN / 瑞利

两项实特征组成一个复符号：`x=(z1+j*z2)/sqrt(2)`。分组单位功率后，公开 UEP 幅度使整帧平均 `E|x|²=1`（非零分支）。`n~CN(0,N0)`，名义 `SNR=1/N0`。瑞利为含随机相位的 `h~CN(0,1)`，不是仅正幅度的瑞利变量；AWGN 为 `h=1`。

### FSO IM/DD 候选实现

`h = h_path * I_GammaGamma * h_pointing`；`I=Gamma(alpha,rate=alpha)*Gamma(beta,rate=beta)`；`h_pointing=A0*U^(1/xi²)`，`h_path=10^(-loss_db/10)`。不按每张图重新归一化衰落，不抹去指向/路径损失。

神经特征有正负值，因此使用有界差分光强对：`s=tanh(z)`，`u+=a(1+s)`，`u-=a(1-s)`。光强均非负，每对平均光强为 `a`，全帧平均光强为 1；最大光强随公开 UEP 表变化并记录。每个实特征占 **两个光强时隙**。接收端作差除 2，其热噪声方差变为每时隙方差的一半；此因素已进入估计和均衡。饱和映射不是无损映射，需要微调适应。

名义光学 SNR 定义为单位平均光功率的平方除以每时隙热噪声方差，响应度设 1。它不是衰落后的即时 SNR，不与 RF 的同一 dB 数字直接等价。预设弱/中/强只是可控压力档位，不是已测天气等级。尚未模拟散粒噪声、光电前端饱和、带宽/脉冲成形、同步误差、湍流相关时间、天气数据及真实链路预算。

### CSI / 控制 / 开销

每个相干块 32 个导频；残差估计噪声，样本方差分母为 `N-1`。默认导频 CSI + 正则化线性 MMSE 式均衡，将估计方差计入正则项。FSO 的有界符号先验方差并非严格为 1，故此均衡是稳定近似，不是对非高斯符号的精确贝叶斯 MMSE。

接收端以块可靠性的保守分位数选择模式。模式在独立反向 RF-AWGN 链路上使用长度 64 的三元正交码；发送端另用长度 64 的前向模式头声明实际执行模式。它不是 CRC，也不保证无误码。拒绝模式头时标记擦除；置信错误也保留，绝不使用发送端真模式修正。不存在条件 ARQ 或免费反馈。

默认一个慢衰落块：

| 项目 | 全量 RF | 全量 FSO | Common-only RF | Common-only FSO |
|---|---:|---:|---:|---:|
| 神经实特征数量 | 4608 | 4608 | 512 | 512 |
| 物理载荷次数 | 2304 复符号 | 9216 光强时隙 | 256 复符号 | 1024 光强时隙 |
| 前向导频+模式头 | 96 复符号 | 192 光强时隙 | 96 复符号 | 192 光强时隙 |
| 前向总量 | 2400 | 9408 | 352 | 1216 |
| 反向开销 | 64 实值 RF 符号 | 64 实值 RF 符号 | 64 实值 RF 符号 | 64 实值 RF 符号 |

反向资源单列，不把异质时隙简单相加。跨物理系统比较需要额外给定符号率、时延与光/RF功率预算。Common-only 预算比 full 小，不能假装二者等码率。`no_common` 是零掩码诊断；RF 中被置零分支的能量不重新分配，不能作为严格等能量的论文主消融。

`blocks>1` 表示独立相干间隔，不是把同一次慢衰落复制成免费分集。交织只能利用确实存在的独立间隔；同块内文本重复只能改善独立噪声，不能摆脱共同深衰落。多块导频与头开销按块增加；真实时延/相干时间待补测。

## 网络改动及作用有限的模块

- 保留 VAE/CLIP 与主要 C/I/T 主干，先严格载入旧权重。新 checkpoint 含完整 V10 模型，不覆盖旧文件。
- 移除旧内容相关 top-k 打包及未传输索引。图像使用公开空间分散置换的前缀；文本固定 77 个学习特征槽循环重复，不读取有效文本长度。这牺牲了一部分内容自适应性，换来可实现的接收端合同。T192 仍不代表 192 个不同词。
- 默认旁路早期文字注入图像的融合，使 Common 的图像视图不再预先看到源文字；保留开关供公平对照。不能据此宣称已实现互信息意义上的严格解耦。
- 修复图像门控旁路：零文本可靠性时，图像 refiner 也从门控后的图像特征开始。已有针对这一边界的因果测试。
- Common 粗图像头损失为零，默认不执行；残差修正原本只对外部 token 擦除率的中间区间激活，而新流程未模拟该类擦除，因此默认不执行。权重保留用于兼容，不物理删除。私有分支的无用参数/训练范围也被冻结。
- 新增 2256 参数的接收适配器（16 维条件下），输入仅为均衡后 token、导频可靠性和幅度统计。零初始化和有界残差便于受控微调。不是为了堆叠大型模型。
- UEP 为公开、固定、可消融的模式表：重建 C/I/T 相对功率 1.5/1/1；混合 3/1/1.5；生成 6/1/2.5，再归一化到相同全帧平均功率。FSO 用光强权重，RF 用平方根幅度。表不是训练所得最优解；更不能把功率增加误记作带宽增加。

## 训练方法

默认初始化 V9-A 最优权重，1 轮冻结主干的接口适应，再 5 轮小学习率联合微调。骨干始终冻结。每个批次在 AWGN、瑞利、FSO 弱/中档轮换，随机采样 -5/0/5/10/20 dB；强 FSO 留作信道失配压力测试。支持单信道同预算训练作对照。

主任务沿用图像 latent/像素/结构和文本损失。每 4 步增加一次真实 32-token Common-only 语义对齐，覆盖不同信道；另每 4 步做一次 20 dB AWGN 回放。后者降低遗忘风险，但不保证新版必然保持旧分数。训练轮间使用各信道损失的移动平均增加难信道权重，属于启发式 worst-group 加权，不是带理论保证的分布鲁棒优化。

验证在独立 validation IDs 的多个信道/SNR 上进行，以 `0.5*平均分+0.5*最差组分` 选 checkpoint，组分为 `PSNR+2*Common cosine+token_acc`。该分数是预先固定的选模代理，不是发表时应使用的唯一指标。正式训练建议扩大 validation 到 500；快速试验可用 64。

图像预处理保持 128 方形中心裁剪以控制变量；取消与左右位置描述不一致的随机镜像。裁剪和 CLIP77 截断仍是限制，完整图像 letterbox / 更长文本编码器应另做一组实验，不能与信道收益混算。

## 候选研究故事与不可越界的结论

候选主张：在有湍流/指向损失和不完美 CSI 的信道中，把 Common 从附属压缩分支变为低带宽语义保底层，并用可测接收可靠性协调差异保护、像素恢复和后续生成。它组合了已有通信原理；只有通过同资源、独立划分、多随机种子的实验才能谈贡献强度。

不主张“Common 单独恢复真实精细原图”；优先测 Common-only 检索、短描述和关键对象保留。扩散仅作为接收描述驱动的候选生成，旧 V9-B.2 门限在 FSO 分布下不能直接当有效。预览脚本保留所有候选，未实现重新校准的 FSO 选择器；不能把候选展示当作选优机制已完成。

## 实验计划

必做：零微调失配基线；AWGN-only、FSO-only 与混合训练同预算；有/无 UEP（分别训练）；有/无接收适配器；pilot vs perfect CSI 与 MMSE vs ZF；Common-only vs 随机 Common；关闭 Common-only 辅助任务重新训练；至少 3 个训练种子、每图多个独立信道重复。

报告 PSNR/SSIM 与尾部分位数、文本 BLEU2、Common 到文本检索 R@1（注明图库大小）、头错误/拒绝率、实测平均/峰值功率、物理开销、吞吐/时间。按 image_id 聚合后做配对置信区间，不把同图多次传输当独立图片。CLIP 同族指标需要独立对象评价或盲评补充。

然后：FSO 参数失配、额外路径损耗、指向误差、块相关性/导频陈旧、有限反馈 SNR 和过时模式。扩散强度/拒绝阈值只在 calibration split 调，test 只用于冻结后一次报告。后续再加入独立图像语义教师、语义结构条件扩散或真实光链路测量。
