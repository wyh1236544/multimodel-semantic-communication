# FSO 单次连续特征带噪训练：文献调研与实验计划

状态：研究提案，尚未实现或运行。检索与源码核对日期：2026-10-11。

本轮只查文献、核对现有实现并制定实验；没有修改模型、启动服务器任务或更新 GitHub 代码版本。历史源文件、权重、数据划分、失败和结果全部保留。

## 1. 核心决定

下一阶段优先研究“针对 FSO 训练的单次连续联合信源信道编码”，而不是继续以冻结的数字 A 特征重复传输来代表 DeepJSCC。研究问题限定为：在相同图文输入、总信道资源、光功率约束和尽量相同网络规模下，FSO 带噪训练能否减少连续特征的语义损失；图文关联又能否提供独立于训练信道和网络规模的额外收益。

主方案保持图像和文字共同转为 token，接收端没有原始文字、原始图像或真实信道参数旁路。主实验每条业务只发送一次；保留公开导频和必要帧头，并计入开销。单次发送不意味着网络不能学习分布式冗余。

文献说明这条方向有依据，但不能保证它在本项目中胜出，也不能保证所有低 SNR 情况都能恢复原来的细节。

## 2. 检索范围与证据等级

检索围绕 DeepJSCC / discrete-time analog transmission / FSO / turbulence-aware end-to-end training / semantic contrastive learning / multimodal reconstruction。优先原论文、作者预印本和高校作者稿，而非聊天历史、综述的二手数字或非官方复现。

下面九篇核心工作中，DeepJSCC、ADJSCC、WITT、DTAT-FSO、TRFSO、C-JSCC、DiffJSCC 核对了全文中的相关方法和结果；FSO-SC 和 YOTO 的本文结论限于可核验的出版社/高校摘要，不假装已获得其完整实验细节。另用 Farid–Hranilovic 的原论文核对慢衰落及指向模型。

这是有针对性的文献调研，不是穷尽检索，也不是“首次提出”的新颖性证明。不同数据集、分辨率、训练量和符号预算下的论文数值不能拼成方法排名。

## 3. 九篇核心论文及采纳边界

### P1. DeepJSCC：连续符号需要针对信道联合训练

Bourtsoulatze、Kurka、Gündüz，*Deep Joint Source-Channel Coding for Wireless Image Transmission*，IEEE TCCN，2019。图像直接映射为功率归一化复符号，中间放置噪声/慢瑞利信道，编码器与解码器共同优化 MSE。其低 SNR、低信道预算实验优于 JPEG/JPEG2000 加理想信道编码，并展示训练/测试 SNR 失配下的渐进退化。不是 FSO 或图文联合恢复证明。[原论文](https://arxiv.org/abs/1809.01733)

采纳：端到端学习抗噪表示、固定功率/符号预算、失配测试。不能把“已有语义网络输出连续数值”直接等同于已优化的 DeepJSCC。

### P2. ADJSCC：一个模型覆盖 SNR 区间

Xu 等，*Wireless Image Transmission Using Deep Source Channel Coding With Attention Modules*，IEEE TCSVT，2022。用 SNR 条件化注意力调节特征，训练 SNR 均匀采样 0–20 dB；一个模型覆盖整个区间，减少固定 SNR 模型的失配损失。文中最大约 6 dB 的比较涉及特定训练 SNR 的失配对照，不能当成通用模块增益。[作者稿](https://arxiv.org/abs/2012.00533)

采纳：区间带噪训练；条件模块放在后续独立消融。不能将仿真真实 SNR 免费提供给接收器或发送器。

### P3. WITT：Transformer 主干和强数字对照

Yang 等，*WITT: A Wireless Image Transmission Transformer for Semantic Communications*，ICASSP，2023。Swin 主干加 Channel ModNet，训练 SNR 均匀采样 1–13 dB；对照包括 BPG、5G LDPC 和 QAM。图 5 的一个 10 dB 示例，同一 R=0.0208 下 WITT 为 26.16 dB、原 DeepJSCC 为 24.81 dB；这是单图示例，不是数据集均值。[原论文](https://arxiv.org/abs/2211.00937)

采纳：明确资源合同、像素和感知评价分开、允许数字基线选择合理调制/码率。不立即用更大 Swin 替换现有主干，否则无法辨别 FSO 训练收益和容量收益。

### P4. DTAT-FSO：连续符号如何接入光链路

Huang 等，*Atmospheric Turbulence-Immune Free Space Optical Communication System based on Discrete-Time Analog Transmission*，2024 作者预印本，关联期刊 DOI 10.1007/s11432-024-4415-7。训练使用 AWGN，SNR 为 1–14 dB；损失包含 MS-SSIM 和 PAPR。光链路验证覆盖 IM/DD 与相干架构，作者报告接收灵敏度分别改善 2.5 dB、0.8 dB；后者的不规则星座也增加了载波相位恢复难度。这些不是 PSNR 增益。[原论文](https://arxiv.org/abs/2409.11928)

采纳：连续幅度符号必须经过成形、调制和接收 DSP；约束真实波形峰值；使用支持不规则星座的公开导频同步。题目中的 immune 不表示任意深衰落下完全无损。

### P5. TRFSO：最直接支持本轮“FSO 带噪训练”

Zhang 等，*Robust End-to-End FSO Transmission with Joint Coding Modulation and BiLSTM-Based Channel Modeling under Atmospheric Turbulence*，2025 作者预印本。先在 AWGN 预训练，再采集实际 FSO 发收符号训练 BiLSTM 代理，最后冻结代理、联合训练收发网络。30 GBaud IM/DD 实验中，相同架构的 FSO 训练方案相对 AWGN 训练方案，在强湍流下平均改善约 3.54 dB 的 MS-SSIM（dB 表示）；不是 PSNR 增加 3.54 dB。[原论文](https://arxiv.org/abs/2509.03835)

采纳：相同网络、相同训练预算，只改变训练信道；评估必须回到真实或独立的详细链路。作者也观察到 AWGN 训练模型在 AWGN 上更优，FSO 专用训练并非全信道无代价提升。

### P6. FSO-SC：数字语义路线也是强候选

Chen 等，*Free Space Optical Semantic Communication for Satellite Remote Sensing Image Transmission*，IEEE TCOMM，2025，DOI 10.1109/TCOMM.2025.3562356。可核验摘要使用 VQ-VAE、空间归一化和 Málaga 信道；28 GBaud 仿真，10 Gbps 等效实验；报告同等图像质量下约 60% 开销减少，以及至少 4 dB 接收灵敏度增益。本文不是连续模拟 JSCC，详细训练超参尚未核验。[出版社摘要](https://doi.org/10.1109/TCOMM.2025.3562356)

采纳：保留数字语义压缩方案，不预设连续必胜。其百分比不能照搬到现有 C/I/T 模型。

### P7. C-JSCC：语义结构可以进入抗噪训练

Hua 等，*Semantics-Guided Contrastive Joint Source-Channel Coding for Image Transmission*，WCSP 2022，论文集在线日期 2023。在重建损失外加入监督对比损失；CIFAR-10 实验报告 Gaussian 信道下约 2–3 dB 的 PSNR 改善，也提高分类表现。语义损失权重过大时存在重建—分类权衡。它不是图文融合或 FSO 的直接证据。[作者全文](https://jmota.eps.hw.ac.uk/documents/Hua22-SemanticsGuidedContrastiveJointSourceChannelCodingForImageTransmission.pdf)

采纳：在基础 FSO 训练有效后，再单独验证语义保持损失；不能只优化图像 MSE，也不能只让 CLIP 分数好看。

### P8. DiffJSCC：感知效果与忠实恢复不是同一目标

Yang 等，*Diffusion-Aided Joint Source Channel Coding For High Realism Wireless Image Transmission*，2024 作者预印本。由接收端初始重建提取空间和文字条件，再引导扩散；1 dB 下用 3072 复符号重建 Kodak 768×512 图像。正文报告感知指标改善时，PSNR 约下降 1.5 dB。文字来自接收图，不是无损传来的原文。[原论文及全文](https://arxiv.org/html/2404.17736v1)

采纳：把感知质量和原始语义忠实度分开；本轮主实验先不启用扩散，避免生成先验掩盖通信增益。

### P9. YOTO：“重建描述”不能替代原文传输

Yao 等，*You Only Transmit Once: Unified Generation and Comprehension for Efficient Semantic Communication*，2026，IEEE JSAC 作者稿/高校摘要，DOI 10.1109/JSAC.2026.3655643。摘要报告 AWGN/Rayleigh 的 6 dB 条件下 PSNR 超过 30 dB，并由解调视觉数据生成描述。采用数字调制自编码器，不属于 FSO 单次连续训练；该摘要数字缺少本项目同预算条件，不能用于目标值。[高校作者记录](https://discovery.ucl.ac.uk/id/eprint/10221082/)

采纳：统一 token 可支持恢复与理解任务，但必须区分生成图像描述、恢复原句、利用发送文本辅助图像三种不同问题。

## 4. 必须纠正的比较口径

1. MS-SSIM 的 dB 表示常用 −10 log10(1−MS-SSIM)，与 PSNR 是两种指标。接收灵敏度增益是达到特定质量所需光功率的横轴变化，又是另一种增益。不得合并。[WITT 的指标定义](https://arxiv.org/pdf/2211.00937)
2. 论文中的 10 次、50 次信道试验主要用于统计随机信道结果，不意味着将 10/50 份相同业务合并为一次交付。[DeepJSCC 的评价设置](https://arxiv.org/html/1809.01733v4)
3. 使用三种训练信道、图文联合处理、增加网络规模、加入扩散、增加重复发送，分别是不同自变量。任何一项收益都不能替其他项作证明。
4. 原文无信道也恢复不好时，主要问题可能是源表示、文本解码器或截断；FSO 训练只能针对新增信道损伤，不能据此许诺逐字无误。
5. 连续符号没有未经定义的 bit BER。使用特征 MSE/EVM/SNDR；数字路线报告 pre/post-FEC BER、CRC 和业务失败率。共同终端比较图像、文本、语义忠实度、时间及能量。

## 5. 与现有项目的衔接

已核对 `optical_realism_v3/run.py`：当前明确冻结 A，记录 `trained=false`，并标记 `analog_is_frozen_digital_A_compatibility_not_optimized_DeepJSCC=true`。因此原来的连续结果不能证明“针对这条相干 FSO 链路重新训练的单次连续方案没有优势”。

沿用当前 VAE/CLIP、128×128 输入、C32/I224/T32、width16，初始固定 4608 实特征，即 2304 复符号。不增加原文 UTF8 旁路，不把 A 误称为图像独立模型。第一轮暂不改骨干、分辨率、文本长度或模式自适应策略。

拟议数据流：图像与文本 → 原有联合 token 主干 → 可训练连续信道映射与功率约束 → FSO 信道 → 导频估计/稳定均衡 → 可训练信道逆映射与联合恢复 → 图像、文本、语义评价。

VAE/CLIP 先冻结；新增收发映射先小步热身，随后联合微调 token 投影、融合/恢复模块与收发映射。不是只训练接收端去噪器。旧 A 的相同初始状态用于所有新对照；新增映射以恒等/零残差方式初始化，便于单独检查接口损失。

## 6. FSO 训练信道与真实性边界

### 6.1 先采用两级结构

一级训练采用可微、随机的等效 FSO 信道；二级评估使用现有较详细的光波形与接收 DSP。训练层可以加入可微 RRC、峰值/裁剪约束以及经校准的相关残差。评估不能只在训练代理自身上完成。

随机 Gamma-Gamma 采样不妨碍梯度对发送特征反传：一次前向中抽到 h 后，y=hx+n 对 x 仍可微。因此本轮不必先实现 BiLSTM。若以后有实际链路发收数据，再考虑 TRFSO 式代理；当前模拟器生成的数据只能称“仿真代理数据”，不能称“实测信道”。

如果训练代理，不能仅用确定性 MSE 预测来替代全部随机噪声；需验证条件残差分布、时间相关性和失锁尾部，并按不同链路工况/波形划分验证集，防止模型利用代理误差获得虚假收益。这是本提案的改进假设，不是已实现成果。

### 6.2 明确相干/IM-DD 两种定义

主线沿用当前相干架构，等效式为 y=hx+n，其中 h=sqrt(L·I_turb·I_point)·exp(jφ)。Gamma-Gamma 描述光强/功率随机量；不能直接当作相干光场幅度。IM/DD 是另一分支，须使用非负光强及对应探测噪声，不把两者同名义 dB 数值作无条件对比。

训练前先归一化发送功率，衰落后不逐帧重新归一化，也不按每帧衰落重新设置噪声以维持相同 SNR。简化固定噪声条件下，gamma_inst=|h|²·gamma_0；完整链路则按 ASE/散粒/热噪声等计算，不硬套这一简式。

FSO 按帧内准静态衰落建模，不能把每个 token 当作独立湍流。Farid–Hranilovic 讨论的衰落时间约为毫秒量级，相对高速符号间隔很长。[原论文](https://www.ece.mcmaster.ca/faculty/hranilovic/publications/articles/07/jlt06IEEEFinal.pdf)

### 6.3 初始物理合同

- 沿用 64 GSa/s、4 SPS、16 GBaud、RRC 滚降 0.1；先不同时扫速率。
- 距离、1550 nm 波长、孔径、光功率/EDFA、损耗和噪声定义固定记录；弱/中/强湍流和指向偏差分开抽样。
- alpha/beta 要说明是模型推导还是人为压力档位；不得直接把别的论文的 Cn² 或标签当成本实验同等天气。
- 接收器只用导频估计信道；发送器不免费得到瞬时真值，首轮不新增反馈。
- 既有 Gamma-Gamma/指向模型是等效单模接收模型，不等于完整波前传播或已校准的户外光链路。

2304 个纯载荷符号在 16 GBaud 下约 0.144 μs；这不含导频、帧头、滤波尾部和保护间隔，不是实际总交付时间。一次发送减少符号次数/时间/能量，并不在相同符号率下自动缩窄频谱。

## 7. 训练策略：先检验机制，再增加创新

下面是本项目的初始设计，不是照搬某篇论文、也不是已验证最优超参。

### 阶段 0：无信道上限与接口审核

不训练，核对 32–64 个已有 validation 样本的无信道图文恢复、原始文本截断、裁剪与描述是否匹配、新连续映射的恒等性。先识别错误来自源表示还是信道；保存完整图片和文本。检查 V3 单次发送 R=1 的同步、计费和拒收行为。

只统计模拟结果不能替代真实设备标定。如果 clean 文本输出已很差，报告该瓶颈；若改文本解码器，要给所有对照相同改动，不能只修主方法。

### 阶段 1：三组新训练，回答“FSO 带噪训练有没有作用”

| 编号 | 训练设置 | 主要回答 |
|---|---|---|
| M0 | 原有冻结 A，单次连续传输；不新训练 | 现有方法参照 |
| M1 | 相同新增收发接口、相同步数，无新增信道噪声微调 | 额外训练/接口适应本身的收益 |
| M2 | 同网络同预算，AWGN 带噪微调 | 一般抗噪收益 |
| M3 | 同网络同预算，FSO 带噪微调 | FSO 衰落匹配是否带来额外收益 |

M1 并非“从未带噪训练”的模型：它继承相同历史 A，只表示这一轮微调不新增信道噪声。M1–M3 相同初始化、数据次序、参数量、优化器、更新步数、符号预算与验证规则。

初始训练：固定 2000 个训练图文对，固定 128 个 validation 对，单个可复现随机初始化/运行身份，不先进行多训练种子矩阵。4 个等预算 epoch，其中前约 0.5 epoch 进行共同接口热身；后续 FSO 主阶段不混入 AWGN 锚点，而保留高 SNR FSO 样本。

建议初始名义 SNR 覆盖 −5–20 dB，50% 采样 −5–5 dB、30% 采样 5–10 dB、20% 采样 10–20 dB。M2/M3 使用同一名义 SNR 分布；M3 另外随机弱/中/强湍流与指向损伤。该分布是待验证假设，不代表测得的接收 SNR 分布。先校准，避免样本几乎全部深失锁或几乎全部高 SNR。

用当前兼容的 FP32/no AMP 策略。先以 100–200 步实测加载、训练、验证开销；共同记录 batch、梯度累计、更新次数和额外前向。先设置每个新模型 2–3 GPU 小时的筛选预算，总 6–9 GPU 小时，不把预算称为预计完成时间。触及预算时保留未完成记录，不用不同完成步数下的结果冒充等预算对照。

### 阶段 2：有效后，最多增加两个核心对照

M4：在 M3 的训练信道上增加语义保持目标；与 M3 从相同初始化训练相同步数，不给 M4 免费追加训练。语义目标可由冻结教师对原始图像/文字的表征提供，训练时监督接收端语义；接收器推理时不能看原始信息。基本重建、文本 CE 与 PAPR 约束保持一致。

M5：与选定的联合方案同预算的图文独立处理模型。隔离跨模态交互、按公开分配分别编码恢复；保持总 token/符号数和可训练参数尽量匹配，记录实际差异。重新训练，不把联合模型测试时关模块当作公平独立基线。

先验证“FSO 训练增益”，再验证“语义损失增益”，最后验证“联合处理增益”。不要把三者合并成一项贡献。接收可靠性条件模块、可学习不等功率保护、码率变化都是后续选项，不在第一轮一起加入。

## 8. 损失与改进假设

基础目标包含现有图像 latent/像素/结构恢复、有效文本 token 的交叉熵、发送功率约束和 PAPR 项。PAPR 不只量原始 token，也记录 RRC 成形后的波形峰值、裁剪比例和调制器输出约束。

M4 单独加入语义项：保持接收图像与原图的语义一致，并用配对文本辅助表征监督。相似场景/不同对象数量、位置关系或否定词作为困难负例；不把所有不相同描述都视为错误。对比损失只在训练数据构建，不访问测试标签。损失权重只在 validation 选择，先用少量候选，不进行大规模组合搜索。

预期机制是“重要语义在特征空间获得更稳健的表示”，而不是“在接收端凭先验生成一张好看的图”。首轮不加扩散。若后来研究生成，需要另报对象/关系错误、幻觉率与生成延迟。

## 9. 评价矩阵与公平数字比较

### 9.1 信道评价

先固定三种湍流强度，名义 SNR 网格 −10/−5/0/5/10/15/20 dB；−10 dB 可作为超出训练区间的压力条件。详细物理链路另扫光功率，报告实际 ROP、噪声分项 SNR、导频估计和均衡后 EVM/SNDR 的分布，不将这些量混成一个 SNR。

每图每工况至少 3 个独立信道抽样，仅用于统计，每次恢复都只使用该次单帧。固定图像/湍流与指向抽样作方法间配对；不同长度波形不能假称完全相同的噪声数组。失锁/CRC 失败/拒收全部保留；同时报告全部业务的质量和成功业务的条件质量。

### 9.2 评价指标

| 类别 | 初始指标 | 注意事项 |
|---|---|---|
| 图像忠实度 | PSNR、SSIM/MS-SSIM、低尾分位数 | 不只展示成功图或平均值 |
| 感知质量 | 可用时 LPIPS | 不等同于正确对象/关系 |
| 文本逐字恢复 | WER、CER、有效 token 准确率 | 去除 padding；明确截断和文本范围 |
| 文本语义 | BLEU/语义相似度、关键事实保留 | 不能只依赖同族 CLIP |
| 跨模态语义 | 固定图库检索 R@1、对象/数量/空间关系正确率 | 明确图库大小和多正例；人工盲评或独立指标交叉核对 |
| 连续特征 | 分 C/I/T 的 MSE、EVM、均衡后 SNDR | 不伪造 bit BER |
| 数字链路 | pre/post-FEC BER、CRC、失锁/拒收率 | 失败不得删掉 |
| 资源 | 总符号、AWG 样点、光学 airtime、能量、计算时延 | 物理时延与 Python 墙钟分开 |

按 image_id 聚合后进行配对 bootstrap；多个信道抽样不当作新增独立图片。单次训练的区间主要表示图像/信道抽样的不确定性，不表示训练种子稳定性。正式结果才考虑新增独立训练种子。

### 9.3 数字基线

保留两类：相同源语义表示经量化/FEC/QPSK或16QAM传输，以及 JPEG/JPEG2000 + UTF8 + FEC 的业务基线。所有路线传同一图像和约定文本范围，考虑量化 scale、包头、CRC、终止/填充、导频及反馈。

现有 K7 卷积码不是最优传统系统；先比较现有基线，但相应结论只限该配置。进一步加入公开 LDPC 强数字基线前需核对当前服务器环境，不在调研阶段安装依赖。调制/码率在 validation 合理选择；逐工况最优配置包络可作为理想自适应参考，但不能假装接收端真实实现了免费选择和反馈。

同时做固定平均发射功率 + 相同总符号/时间上限，以及质量—时间/能量 Pareto 比较。相同峰值和 4 μs 上限不是等实际能量；固定总能量是另一份清晰标记的实验，不能与固定平均功率混用。连续值不按 FP32 文件字节计算“链路压缩比”。

首轮只用当前 2304 复载荷符号预算；如方向有效，再考虑 1152/576 的紧预算测试。需要重新训练相应码率或公平的统一码率模型，不能任意截掉特征后直接归因于连续方法。

## 10. 语义因果诊断与可视化

1. 同一图片、匹配文本和固定另一图片的错配文本，对照发送 token；保证资源相同、记录 donor，避免 batch=1 shuffle 无效。替换输入文本会同时改变联合编码，共同用于诊断，但不能据此定位唯一分支。
2. 要单独测接收文本的帮助，固定已发送的 C/I 和同一信道，仅替换/遮蔽接收 T；不能重新生成 Common。此诊断与公平重新训练的 M5 分开报告。
3. Common-only、错误 Common、等资源随机 Common 用于判断传来的共同特征是否包含样本相关信息，不能拿低预算 Common-only 与 full 当同码率主对照。
4. 做不含业务信号的接收控制，判断纯先验输出和真正收到的信息；极低 SNR 的“看起来合理”不是成功恢复证明。

预定四类结果图：M1/M2/M3 的 PSNR 与语义—SNR 曲线；错误/失败概率与信道资源曲线；同 image_id 的各 SNR 图像和文字完整面板；联合/独立与错误文本控制的配对增益图。每张图对应一个问题，不把接收同步修复、抗噪训练和联合处理混为同一增益。

## 11. 继续/停止条件与可支持的结论

预先选择实际的低 SNR 样本组。作为方向筛选工程门槛，可考虑：M3 对 M2 的低 SNR 图像平均改善至少约 0.5 dB，或关键语义正确率改善至少约 5 个百分点，且高 SNR 恢复不过度退化、失败率不恶化；同时检查配对区间与原图事实。阈值是本提案的实用选择，不是文献承诺、统计显著性判据或投稿保证。

- M3 优于 M2：支持 FSO 匹配训练减少对应损伤，不自动证明图文联合有用。
- M3 优于 M1：支持这一轮带噪微调的价值，不是历史模型从未带噪训练的对照。
- M4 优于 M3：支持所加语义目标的作用。
- 联合优于 M5：才支持同资源/近似同规模的跨模态额外收益。
- 训练过的连续路线在低 SNR、短帧预算下优于强数字对照：支持特定区域的连续优势，不必在高 SNR 或精确文本恢复上全面领先。
- 如果仅感知质量更好而原图事实/文字变差，按目标权衡报告，不称语义无损。
- 如果只在训练代理上改善、详细链路失败，先检查代理失配，不扩大训练。
- 如果三组均接近无信道上限或均不改善，先定位源表示上限、文本头、同步/深衰落和损失目标；不再自动启动大量消融。

预期交付是可核验的方向结论，而不是预设的最优 PSNR。后续实现经用户授权后，在原项目内新增隔离模块，提供源码压缩包、校验、安全解压/安装命令和 GitHub 保存；本提案不启动这些动作。
