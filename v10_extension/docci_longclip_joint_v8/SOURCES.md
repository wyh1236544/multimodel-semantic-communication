# Primary sources and implementation boundaries

- [DOCCI official dataset](https://google.github.io/docci/), Onoe et al., *DOCCI: Descriptions of Connected and Contrasting Images*, ECCV2024. Official Google Storage full descriptions/images; original paired human descriptions. Native high resolution does not itself prove larger JSCC input causes joint benefit. CC BY4.0 applies to dataset; images/descriptions are not bundled with source code.
- [Long-CLIP authors' implementation](https://github.com/beichenzbc/Long-CLIP), Zhang et al., *Long-CLIP: Unlocking the Long-Text Capability of CLIP*, ECCV2024. The native248 context is retained. `vendor_longclip.py` is byte-identical to upstream `model/model_longclip.py` Git blob `9045ac614db11deb69521b67085d39355162d705`, obtained and fully inspected before use; no remote code installation. `LICENSE_LONGCLIP.txt` includes the author's Apache2.0 license, and `LICENSE_OPENAI_CLIP.txt` includes upstream OpenAI CLIP MIT copyright. These authors' code/weights are not claimed as new model design.
- [Long-CLIP-B official checkpoint](https://huggingface.co/BeichenZhang/LongCLIP-B/blob/main/longclip-B.pt): official SHA256 pinned in code before Torch1.12 pickle loading. Native ViT-B/16 input224 is separately processed from the512 VAE/JSCC image path.
- [BART original paper](https://aclanthology.org/2020.acl-main.703/), Lewis et al., ACL2020. Frozen BART-base encoder/decoder are authentic pretraining; we reuse the project's existing learned query-slot compression implementation from V4, extending public lengths and slots. No lossless guarantee; attention bottleneck capacity must be measured on DOCCI.
- [Diffusers0.20.2 model loader](https://github.com/huggingface/diffusers/blob/v0.20.2/src/diffusers/models/modeling_utils.py) confirms offline `output_loading_info` and `low_cpu_mem_usage=False` used here. Existing frozen SD-VAE is a pixel latent codec, not a diffusion denoising pipeline. No UNet sampling is used.

New window attention+overlapping convolution is an independent small spatial codec, not a reproduction of Swin/DeepJSCC or any paper's reported numbers. Long captions are chunked only for frozen Long-CLIP feature extraction; native BART sees full captions within the selected cap. Raw source token lengths, IDs, pixels, VAE source latents, CLIP teacher features and aspect rectangles are TX/loss/evaluation material, never RX input.

The complete optical waveform/DSP is the user's historical V3 software simulator, with assumed—not laboratory calibrated—parameters. The new differentiable FSO symbol training proxy is not its exact differentiable replacement. A positive result must survive actual physical evaluation and wrong-received-modal controls before being described as joint benefit.
